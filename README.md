

\# ONEBITE – Restaurant Website



A modern, responsive restaurant website concept created as part of \*\*Future Interns Full Stack Web Development Internship – Task 3\*\*.



\## About the Project



ONEBITE is a restaurant website demo designed to provide visitors with an attractive and user-friendly online experience.



The website includes food categories, an image gallery, an introduction section and contact information.



\## Features



\- Modern dark-themed design

\- Responsive layout for mobile and desktop

\- Navigation bar with smooth scrolling

\- Restaurant introduction section

\- Food category cards

\- Food image gallery

\- Contact section

\- Interactive JavaScript functionality



\## Technologies Used



\- HTML5

\- CSS3

\- JavaScript
